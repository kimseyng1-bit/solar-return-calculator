# ✦ 솔라리턴 계산기 (튀르키예식 생일 사주)

태양이 태어난 순간의 위치로 정확히 되돌아오는 **"생일의 순간"**을 계산해, 그 순간 내가 있던 장소를 기준으로 앞으로 1년의 흐름을 읽는 점성 기법(솔라리턴 / Solar Return)을 구현한 인터랙티브 웹 계산기입니다.

빌드나 서버 없이 `솔라리턴_계산기.html` 파일 하나만 브라우저로 열면 바로 사용할 수 있습니다.

## 사용 방법

1. `솔라리턴_계산기.html`을 더블클릭하거나 브라우저(Chrome, Safari 등)로 엽니다.
2. **① 출생 정보** — 생년월일시와 태어난 장소를 입력합니다.
3. **② 작년(가장 최근) 생일에 있었던 장소** — 그 생일에 있었던 나라·도시를 입력합니다.
4. 필요하면 **⚙ 고급 설정**에서 하우스 시스템(기본값: 플라시더스)을 바꿀 수 있습니다.
5. **[1년 사주 계산하기]** 버튼을 누르면 결과가 표시됩니다.

목록에 없는 도시는 각 섹션의 "직접 입력"을 선택해 위도·경도·UTC 오프셋을 입력하면 됩니다.

## 주요 기능

- **정확한 솔라리턴 순간 계산**: 뉴턴 반복법으로 태양이 원국(태어난 순간) 황경으로 정확히 돌아오는 시각을 계산
- **상승궁 · 중천점(MC) · 하우스**: 플라시더스(위도별 가변 폭) 또는 이퀄하우스 선택 가능, 극권(위도 66도 이상)은 자동으로 이퀄하우스 대체
- **행성 배치**: 태양·달·수성·금성·화성·목성·토성 + 천왕성·해왕성·명왕성·평균 노드(북쪽/남쪽)
- **역행 판정, 달의 위상, DST(서머타임) 자동 반영**
- **원국 대비 비교**: Before/After 비교 카드, 스텔리움(천체 집중) 강조
- **어스펙트(행성 간 각도 관계)**: 합·섹스타일·스퀘어·트라인·충을 순조로움/마찰/증폭 3그룹으로 분류, 강도별로 자동 요약·접기
- **월별 흐름**: 하우스를 12개월에 대응시켜 월별 카드로 제공
- **한눈에 보기 요약 카드, 읽는 순서 가이드, 용어 글로서리, 마무리 결론**까지 포함해 솔라리턴을 처음 접하는 사람도 이해할 수 있도록 구성
- 모바일 반응형 레이아웃 지원

## 기술 스택 / 구조

- 순수 HTML/CSS/JavaScript 단일 파일 (외부 라이브러리·빌드 과정 없음)
- 저정밀 궤도요소 천문 공식(Schlyter/Meeus 계열)으로 태양·달·행성 위치, 상승궁, 하우스 커스프를 클라이언트에서 직접 계산

## 정확도

pyswisseph(스위스 에페메리스)를 기준값으로 1920~2080년 다수 무작위 시점, 위도 -46°~64° 지점을 대조 검증했습니다.

| 대상 | 평균 오차 | 최대 오차 |
|---|---|---|
| 태양·달·수성·금성·화성·천왕성·해왕성·노드 | 0.003°~0.04° | 0.1° 이내 |
| 목성·토성 | 0.13°~0.29° | 0.4°~0.7° |
| 명왕성 | 0.99° | 약 2° |
| 상승궁·중천점(MC)·플라시더스 하우스 | — | 0.006° 이내 |

목성·토성·명왕성은 간이 궤도요소 방식의 한계로 다른 천체보다 오차가 다소 크며, 계산기 하단 안내 문구에도 이 내용이 명시되어 있습니다.

## 주의사항

이 계산기는 참고·엔터테인먼트용 도구입니다. 전문 점성 프로그램을 완전히 대체하지는 않으며, 결과는 확정된 미래가 아니라 "이런 방향으로 힘이 실린다"는 해석의 참고 자료로 활용하시길 권장합니다.
